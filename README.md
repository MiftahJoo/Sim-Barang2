SIM-Barang

Sistem Informasi Manajemen Barang

SIM-Barang merupakan proyek aplikasi berbasis web yang dirancang untuk membantu proses pencatatan, pengelolaan, dan pemantauan inventaris barang pada laboratorium dan jurusan.

Tujuan Proyek

- Mempermudah pencatatan data barang.
- Membantu pengelolaan inventaris.
- Mempermudah pemantauan kondisi dan jumlah barang.

Teknologi yang Digunakan

- HTML
- CSS
- JavaScript
- PHP
- MySQL
- Laragon

Pengembangan Proyek

Proyek SIM-Barang dikembangkan secara bertahap berdasarkan materi praktikum Pemrograman Web dari Pertemuan 1 sampai Pertemuan 7.
